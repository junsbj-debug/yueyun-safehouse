# Code of Conduct

Treat participants respectfully. Critique claims and evidence rather than people. Welcome questions and corrections; disclose conflicts of interest and distinguish speculation from demonstrated results.

Harassment, threats, discrimination, doxxing, credential disclosure and posting personal or identifiable conversation data are unacceptable. Do not present unverified security claims or fabricated test results as facts.

The sole maintainer may moderate discussions, request changes or limit participation, and should explain decisions when doing so does not expose sensitive information. There is no established independent appeals body. Governance and a confidential conduct-reporting channel must be confirmed before launch; no response-time guarantee is made.

If no verified private channel is available, ask for one without posting identities or sensitive details. Security concerns use [SECURITY.md](SECURITY.md).
